Конфиги-копипасты из интернетов (лишь немного изменены), которые настроил под себя и для себя.
Выкладываю как есть.

Чтобы применить один из конфигов:
'''bash
stow install ""
'''
Перед применением если у вас есть ваши конфиги, поменяйте название на your_config.bak

В репозитории есть bash-script для реструктуризации ваших конфигов для применения stow если захотите мигрировать.
Для этого достаточно переместить ваш конфиг в директорию (этого репозитория или вашу личную) и запустить скрипт.
